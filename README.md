# Health_insurance_pricing

A health insurance pricing project 

## Project Structure
- `data/`: Datasets (e.g., insurance.csv)
- `src/`: Python scripts and Jupyter Notebooks
- `outputs/`: Visualizations (e.g., bar charts)
- `docs/`: Documentation
- `requirements.txt`: Python dependencies

## Setup
1. Clone the repository: `git clone https://github.com/your-username/health-insurance-pricing.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run `src/analysis.ipynb` in Jupyter Notebook.

## Dataset
- Kaggle Medical Cost Personal Datasets: [link](https://www.kaggle.com/datasets/mirichoi0218/insurance)
